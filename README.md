# hma_sft

Unified mix for **BFCL / MetaTool / τ²**. New package; does **not** overwrite `toolmind_bfcl/`, `toolmind_metatool/`, or `tau2_hma/`.

Training ShareGPT is **not** published here.

Mix names/impls are **not** in the repo. `lexicons/` is empty until you generate:

```bash
export OPENAI_API_KEY=sk-...
PYTHONPATH=. python3 hma_sft/scripts/generate_mix.py --bench all
PYTHONPATH=. python3 hma_sft/scripts/build_eval.py
```

## Where things live

| What | Path |
|---|---|
| **Code** (7 operators, apply/back_map, adapters) | `hma_sft/core/`, `hma_sft/adapters/` |
| **Seeds → LLM generate** | `hma_sft/seeds/`, `hma_sft/scripts/generate_mix.py`, `hma_sft/gen/openai_client.py` |
| **Perturb env (BFCL / MetaTool)** | eval lexicons `hma_sft/lexicons/*/eval/` + compose at eval time |
| **Perturb env (τ² live toolkit)** | `hma_sft/runtime/tau2_mix.py` + `hma_sft/runtime/generated/tau2_impl.py` (after generate) |
| **Eval catalogs** | `hma_sft/data/eval/` |
| **Eval runners** | `hma_sft/scripts/eval_bfcl.py`, `eval_metatool.py`, `eval_tau2.py` |
| **Eval hooks** | `hma_sft/eval/` |
| **实验结果（映射后）** | `hma_sft/exp_records/` |

## Operators

| # | Class | Meaning |
|---|---|---|
| 1 | `ToolRename` | Same tool, synonym surface name |
| 2 | `ArgRename` | Synonym parameter keys |
| 3 | `SchemaReshape` | Singleton↔list; optional args |
| 4 | `CoverReplace` | Drop official tool; insert superseding tool |
| 5 | `SuiteFold` | Merge related tools into one |
| 6 | `NearDistractor` | On-topic tools that must not be called |
| 7 | `FarDistractor` | Off-domain tools |

| Bench | Env | Ops |
|---|---|---|
| BFCL | `H_mix_full` | cover, rename, arg, reshape, near, far |
| MetaTool | `H_mix` | cover, rename, fold, near, far |
| τ² | `H_mix_impl` | cover, fold, rename, arg, reshape, near, far |

## Eval

```bash
PYTHONPATH=. python3 hma_sft/scripts/eval_bfcl.py --mode live_scene \
  --api-url http://127.0.0.1:8001/v1 --model Qwen3.5-4B

PYTHONPATH=. python3 hma_sft/scripts/eval_metatool.py \
  --api-base http://127.0.0.1:8001 --model Qwen3.5-4B

export OPENAI_API_KEY=sk-...   # your key; user-sim = official OpenAI
PYTHONPATH=. python3 hma_sft/scripts/eval_tau2.py --harness H_mix_impl --mode full \
  --model-endpoint http://127.0.0.1:8200/v1
```

Results: `hma_sft/outputs/`. Chat template if you train elsewhere: `qwen3_6`, `enable_thinking: false` (a LlamaFactory chat-template setting, not a perturbation template). Training yamls for reproduction: `hma_sft/train/`.

No perturbation templates exist anywhere in this package: every perturbed surface (tool/arg renames, widen descriptions, cover/suite parameters, optional schemas) is LLM-generated by `scripts/generate_mix.py`, and the apply layer raises `ValueError` instead of falling back to any canned content.
